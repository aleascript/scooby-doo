# Scooby-Doo

A lightweight tabletop mystery game built with Regard and developed in the Resonance design laboratory.

The website is built with Docusaurus from the shared `resonance-site-template` architecture.

## Development

```bash
npm install
npm run start:en
npm run start:fr
npm run check
```

English is the default locale and the canonical language for document IDs, filenames and slugs.
